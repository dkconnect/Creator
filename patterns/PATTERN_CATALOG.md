# Creator Victory Pattern Catalog — Step 48A

All 53 patterns are 7×7 binary templates. A required cell is a `1`; a blank cell is `0`. The existing engine checks these templates at the **center of the 16×16 board**, with no rotation or translation. Every required cell must contain a pawn belonging to the same team. Extra pawns are permitted.

These definitions are a first balancing pass; glyph readability and difficulty should be tested in actual matches before release.
